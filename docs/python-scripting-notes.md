# Python Scripting Notes

## Purpose
This phase adds Python scripting to the project to extend server automation beyond Bash.

## Scripts added
- health_check.py
- system_report.py
- site_monitor.py

## What they do
- health_check.py checks whether the live HTTPS site is reachable
- system_report.py creates a simple system information report
- site_monitor.py logs repeated site status checks to a file

## Why this phase matters
This phase demonstrates beginner-friendly Python automation skills in a DevOps context and shows how operational tasks can be implemented in both Bash and Python.
